# ASM alpha.7.8 Dedicated Review / Version Decision

## Review verdict
**PASS — freeze alpha.7.8 as the official release.**

Alpha.7.8 is a verified improvement inside the existing epistemic/procedure-routing capability family. It expands scale and catches coherent hidden common-cause redundancy that alpha.7.7 can miss, but it does not add a new broad cognitive capability category. Therefore this release does **not** justify alpha.8.

## Architecture review
The new path remains subordinate to ASM's evidence authority. Latent structure is inferred only from read-only dependency diagnostics and never becomes route evidence by itself. The factor correction is monotone with respect to the wide covariance baseline: it can reduce redundant support but cannot create additional confidence. Unsafe factor/covariance solutions fall back instead of being forced through.

The 64-source covariance cap remains deliberately bounded. The latent fit is rank<=2 and requires a coherent, sufficiently dense positive field with minimum fit quality. This is a conservative engineering mechanism, not unrestricted latent-cause discovery.

## Decision / epistemic review
Alpha.7.8 fixes two alpha.7.7 limitations:
1. valid dependency components larger than 16 sources can now use bounded covariance rather than falling back immediately;
2. a coherent weak hidden common cause can be discounted even when no individual pair survives the older activated/FDR dependency graph.

In the reproduced boundary attack, alpha.7.7 routes the correlated majority while alpha.7.8 abstains. In the reproduced independent-source benchmark, the latent gate does not activate in any of the 40 seeds at 64, 100, or 192 trials. In the reproduced shared hidden-cause benchmark it activates 24/24 times at 192 trials.

## Performance review
The additional latent fit has a measurable but still small warm-cache cost in the R2 microbenchmark: ~0.058 ms for alpha.7.7 support weighting versus ~0.092 ms for alpha.7.8. The solve is cached by dependency version/source/signature and is recomputed only when the dependency state changes.

## Consciousness-related review
9/9 checks pass. There is no evidence of subjective consciousness/sentience and no anomaly requiring isolation. The system continues to demonstrate computational self-modeling and limited metacognitive behavior only.

## Breakthrough / milestone review
**No verified scientific breakthrough claim.** Factor models, covariance correction, and Woodbury identities are established mathematics. Their bounded integration into ASM is an engineering/research improvement, not evidence that ASM discovered a new scientific principle.

Milestone remains **M3 — Adaptive Research AI**. Alpha.7.8 materially improves one epistemic subsystem, but it does not yet demonstrate the broad cross-task structural transfer required for M4.
